# 2026-11-09 — 리더 하단 책 진행 막대(V21), 측정값 왼쪽 아래 + 남은 초, PR #32 병합, v0.2.21 릴리스

- 목표/요청: 전체화면 리더 맨 아래에 화면 폭을 쓰는 흰 선으로 책 진행률을 보여 주는 기능(시계 설정 옆에서 켜고 끄기), 그리고 자동 넘기기 측정값을 왼쪽 아래로 시계와 같은 크기로 옮기고 남은 초를 괄호로 표시.
- 도구: Claude Code | Codex | Cursor
- 모델: claude-opus-5-5
- 토큰 사용량(같은 Claude 세션 전체 누적이라 11-08 기록 2개의 숫자를 포함함): 응답 수 115 · 입력 246 · 캐시 생성 532,869 · 캐시 읽기 24,151,338 · 출력 99,153 · 합계 24,783,606 / 모델/토큰: 알 수 없음 (이 폴더와 맞는 세션 기록을 찾지 못함) / 모델/토큰: 알 수 없음 (이 폴더와 맞는 세션 기록을 찾지 못함)
- 핵심 프롬프트(원문):
  > 전체화면일때 그 책의 진행 상황을 맨 밑에 화면 폭을 이용해서 흰색 선이 끝까지 가면 100프로 다 읽은 것 처럼 표시되게 하는 기능(온 오프, 시계표시 기능 있는 설정에수 변경 가능)하고
  > 벤치마킹용으로 시간 나오는 기능은 위가 아니르 왼쪽 아래로 시계랑 같은 크기로 나오게 위치 변경.
  > 시간 옆에는 가로넣어서 (남은 초) 도 표시
  > ㄱㄱ
- 진행 내용:
  1. 기존 "시계 표시" 설정이 저장·연결되는 경로를 그대로 따라 "책 진행 막대 표시" 설정을 추가(DB 마이그레이션 V21).
  2. 화면 맨 아래 3dp 선: 흰 부분이 현재 페이지 ÷ 전체 페이지만큼 차고, 흰 페이지에서도 보이게 반투명 검은 바탕을 깔았음.
  3. 측정값 표시를 왼쪽 아래로 옮기고(시계와 같은 크기), 넘기기까지 남은 초를 매초 갱신해 괄호로 표시.
  4. 컴파일·테스트 통과 → PR #32 병합 → 안드로이드 빌드 성공 → v0.2.21 릴리스.
- 막힌 점 · 실패와 원인:
  - 이 환경엔 Android SDK와 화면 확인 수단이 없어 막대·표시 모습은 실기기 확인이 필요함(미확인).
